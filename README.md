# Blog website

A travel blog with 33 posts, six categories and a custom Destinations taxonomy. Post titles are real places; the article text is placeholder. A self-initiated WordPress practice build by Evan Exanes.

- **Live demo:** https://evanexanes.github.io/blog-website/
- **Case study:** https://evanexanes.github.io/03-case-study-blog.html
- **Stack:** WordPress · Blocksy · Custom Post Type UI · Newsletter · Contact Form 7

## What this repository is

A static copy of the WordPress site, exported with Simply Static so it can run on GitHub Pages.
It is generated HTML, CSS and JavaScript, not the WordPress source: there is no PHP, database or
`wp-config.php` here.

GitHub Pages cannot run PHP, so anything that needs the WordPress server does not work in this copy.
The newsletter sign-up and the Advertise form send through Web3Forms. Search and comments need WordPress and say so when used.
